# CLOUD PHONE LP（GitHub Pages用）

採用したB案の3ステップスライド版です。ビルドは不要です。

## 配置

ZIPを解凍し、`cloud-phone-lp-github` フォルダの **中身** をリポジトリ直下にアップロードしてください。`index.html` と `assets` がリポジトリ直下に並ぶ形です。GitHub Pagesの公開元は対象ブランチのルートに設定します。

フォルダ構成とファイル名を保ってアップロードしてください。`.nojekyll` は静的ファイルをそのまま公開するためのファイルです。

## 内容

- `index.html`：LPトップページ。`404.html` は同じ内容です。
- `fv-b-variant.css` / `fv-b-motion.js`：採用したFVのデザインとアニメーション。
- ステップ：自動受付 → 用件の振り分け → スマホへの転送。右から左へ自動スライドします。
- PC・スマホに対応。手動選択・一時停止・動きを減らす設定に対応。
- トライアル導線：30日間無料トライアルの問い合わせを含む `#section-contact`。
- 電話導線：050-5291-3076。

## フォーム送信

フォームの送信先は未接続です。`replica.js` で送信を止め、入力後に案内を表示しています。問い合わせを受け付ける際は、送信先APIまたはフォームサービスへの接続が必要です。GitHub Pagesだけではメール送信処理は実行できません。

公開用パッケージには、比較案や過去のモックアップを含めていません。
