# DXでんわ 比較用モック V2

公開URL：https://wizao012.github.io/KitsuiTest/
参照サイト：https://mediaseries.medialink-ml.co.jp/mediavoice/dx-tel/

参照サイトの構成・訴求・画像・料金を検討するための比較用モックです。CLOUD PHONE V1.0とは別版です。

## 公開ファイル

`index.html`に主要画像、CSS、アニメーションをまとめています。ビルド不要で、GitHub Pagesの公開元はmainブランチのルートです。WebフォントやYouTubeなどの外部サービスへの参照は残しています。

## 閲覧とフォーム

`noindex,nofollow`を指定していますが、パスワードやメール認証による閲覧制限はありません。

フォームは表示と入力確認用です。送信・トライアル申込・資料請求は実行されません。下層ページの詳細リンクは参照サイトへ接続します。

公開前の版はGit履歴から確認できます。
