# CLOUD PHONE IVR 広告LP

画像中心で構成した静的ランディングページです。ビルド作業は不要です。

## GitHub Pagesで公開する

1. このフォルダ内のファイルをGitHubリポジトリのルートへ配置します。
2. GitHubのリポジトリ設定で Pages を開きます。
3. 公開元としてブランチのルートを指定します。
4. 公開URLが発行されたら表示を確認します。

`index.html`、`styles.css`、`script.js`、`assets/` は同じ階層を維持してください。

## 公開前の確認

- `index.html` のcanonical、OG URL、OG画像URLを実際の公開URLに合わせる
- `robots.txt` と `sitemap.xml` のURLを実際の公開URLに合わせる
- お問い合わせフォームの `action` を本番の送信先へ接続する
- フォーム完了ページと広告コンバージョン計測を設定する
